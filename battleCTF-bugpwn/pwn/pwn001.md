# PWN#001 — Vault

## Statut

Méthode locale préparée ; flag non récupéré dans cette session car le service distant a commencé à refuser ou suspendre les connexions après les essais.

## Résultats confirmés

- binaire non-PIE avec canary et NX ;
- canary à l’offset `0x48`, retour à `0x58` ;
- leak du saved-RBP après les sept octets hauts du canary ;
- gadget `pop rax; xchg rdi, rax; ret` utilisé pour charger `rdi` ;
- chaîne prévue : leak `puts`, calcul libc, puis `open/read/write` sur le fichier du flag.

## Validation

Le retour à la boucle avec un payload contenant uniquement le canary et `0x4012fc` a été confirmé sur le service distant.

Le flag reste `FLAG{REDACTED}` dans cette documentation.
